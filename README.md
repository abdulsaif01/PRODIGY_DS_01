# PRODIGY_DS_01 - Population Distribution Analysis

## 📊 Task Description
Create a bar chart or histogram to visualize the distribution of a categorical or continuous variable, such as the distribution of ages or genders in a population.

## 🎯 Objective
This project demonstrates data visualization techniques using Python to analyze and visualize global population distribution across countries, continents, and age groups.

## 📁 Dataset
- **Source**: World Population Data (2022)
- **Scope**: Top 20 most populous countries
- **Variables**: Country name, population (in millions), continent, age groups

## 🛠️ Technologies Used
- **Python 3.x**
- **Libraries**:
  - pandas - Data manipulation and analysis
  - matplotlib - Data visualization
  - seaborn - Statistical data visualization
  - numpy - Numerical computations

## 📈 Visualizations Created

### 1. Bar Chart: Top 20 Countries by Population
- Displays the population distribution across the world's most populous countries
- Highlights top 3 countries (China, India, USA) with distinct colors
- Shows clear population comparisons

### 2. Histogram: Population Distribution
- Shows the frequency distribution of population across countries
- Includes mean and median markers
- Helps identify population concentration patterns

### 3. Bar Chart: Population by Continent
- Aggregates population data by continent
- Shows Asia's dominance in global population
- Provides continent-level insights

### 4. Bar Chart: Age Distribution
- Visualizes global population distribution by age groups
- Shows working-age population percentage
- Helps understand demographic structure

## 🔍 Key Insights

1. **Population Leaders**: China (1,425.67M) and India (1,417.17M) lead with populations exceeding 1.4 billion each
2. **Continental Dominance**: Asia represents 73.8% of the analyzed population (4,108.4M total)
3. **Working Age Population**: 25-54 age group represents 41.2% of global population
4. **Average Country Population**: 278.48 million
5. **Population Range**: Varies from 71.80M (Thailand) to 1,425.67M (China)
